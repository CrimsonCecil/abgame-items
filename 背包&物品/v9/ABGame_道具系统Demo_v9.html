体验指引

① 背包统一存放 + 🧹整理

武器、消耗品、带功能的战利品、纯战利品全部放在背包，没有专属栏位。打开背包点"🧹整理背包"：按 武器 → 消耗品 → 带功能战利品 → 纯战利品，同类按价值从高到低排，同种消耗品自动合并。

② 武器键 + 武器轮盘（6 格）

底部中间显示当前武器和武器轮盘预览。点武器卡 / 短按 Q = 切到轮盘里下一把；点预览小图 / 1~6 = 直接切；长按武器卡 / 按住 Q = 武器轮盘。再点当前武器不会收起。

③ 拳头

拳头不在背包、也不在武器轮盘里。只有背包里一把武器都没有时，攻击键自动变成 👊；捡到武器立刻自动拿到手上；有武器时不能切回拳头。

④ 消耗品键 / 战利品键

点一下 = 使用当前快捷道具；长按 / 按住 R·G = 轮盘。消耗品轮盘一种一格（同种多堆合并显示总数）；战利品轮盘只放带功能的战利品。某种用完，轮盘自动往前补位。

⑤ 轮盘：指哪选哪

按住后往一个方向轻推 10 像素就选中，也可以直接指向轮盘上的道具；回到中间松手 = 取消。消耗品 / 战利品轮盘默认松手只设为快捷，再点才用。

⑥ 背包：双击 / 拖动

双击武器 = 手持；双击消耗品 / 带功能战利品 = 设为快捷；双击纯战利品 = 放进安全箱。按住拖动可以换格子位置、叠加同种消耗品、拖进安全箱 / 容器 / 丢弃。

⑦ 右下技能

🏃快跑开关（移动耗体力）· 🤸跳跃（可跳上课桌 / 讲台）· 💨冲刺。

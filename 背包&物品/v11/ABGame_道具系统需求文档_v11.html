1. 背景与现状问题

#问题影响v11 对应
①v10 的“道具”类和战利品分开，玩家分不清“哪个能用、哪个只能卖”分类认知成本高，教学难四分类，战利品内部用“可用”角标区分
②簧统一的“道具”不够直觉，投掷物没有独立入口无法支撑“捕捉怪物”玩法新增精灵球类，独立槽位 + 按键
③物品信息层级过多：文字、数值、描述堆在一起屏幕信息过载，阅读成本高只留进度条，删减文字化表达
④背包容量不足，品质基于价值推算，不利于养成体系难以支撑后续品质玩法六级品质统一四类；背包扩至 10×8 可滚动

2. 需求总览与分需求点详述

编号需求优先级v11 方案
【B-0】物品四分类 重写重新划分物品类别高武器 / 药品 / 精灵球 / 战利品四类；去掉“道具”，功能性物品回归战利品
【B-1】武器耐久度 修订耐久度的展示与管理高保留耐久度机制，界面只显示进度条，低于 30% 变红；归零自动切换
【B-2】药品次数 修订药品的次数管理高按次数消耗，用完消失；背包内自动合并堆叠，使用时自动补位
【B-3】精灵球 新增新增精灵球类型与交互高1×1 占一格，独立槽位在武器右侧；背包有球自动装填，长按切换品质；投掷定身怪物
【B-4】战利品 退回战利品的使用与存放高回到 v9 逻辑：部分带可用功能（用完进冷却不消失）；全部可存入安全箱
【B-5】品质体系 新增统一品质标准中全部四类统一六档品质：白 / 绿 / 蓝 / 紫 / 金 / 红

2.1 物品四分类【B-0】

⚔️

武器

核心属性：耐久度

  • 占多格（1×1 ~ 3×1）
  • 持久攻击消耗耐久
  • 耐久只显示进度条
  • 归零自动换下一把
  • 占用 HUD 左侧2 格武器栏
✚

药品

核心属性：使用次数

  • 1×1 占一格，可堆叠
  • 用一次减一次
  • 用完直接消失
  • 背包内自动合并
  • 占用 HUD R 键
●

精灵球

核心属性：定身几率

  • 1×1 占一格，可堆叠
  • 独立槽位，不占武器栏
  • 有球即自动装填
  • 投掷定身怪物，不造伤害
  • 占用 HUD E 键
$

战利品

核心属性：价值 + 可用功能

  • 占多格，尺寸各异
  • 纯战利品：只能卖
  • 功能型：可使用，用完进冷却
  • 不消失，可继续带出去卖
  • 占用 HUD G 键
与 v10 的关键区别：v10 将“可使用的战利品”独立成“道具”类；v11 取消该分类，这些物品仍归属战利品，但保留可使用能力（回到 v9 逻辑），仅把“次数消耗”改为“冷却”。

6. 验收标准

#验收项预期结果
1四分类生效背包中武器、药品、精灵球、战利品各自分区显示；无“道具”分类
2武器耐乵展示卡片上只有进度条，无“耐乵 n/m”文字；低于 30% 变红
3药品次数使用一次减 1，归零后物品消失并自动补位
4精灵球自动装填背包有球时，进入对局即自动装填到独立槽位，优先高品质
5精灵球切换长按槽位出轮盘，按品质从高到低排列；指向即选中，回中心取消
6精灵球投掷点击键位投出；命中显示“定住”，未命中显示“挣脱”；不对怪物造成伤害
7战利品可用性功能型带绿色“可用”角标；点击后产生效果并进入冷却
8战利品不消失使用完成后物品仍在背包，格子显示倒计秒；冷却结束后可再次使用
9六档品质四类物品均有品质；背包格边框、地面光圈、详情卡均正确显示对应颜色
10背包容量与滚动背包为 10×8；内容超出时右侧出现滚动条，可上下拖动
11安全箱限制仅战利品可放入；武器 / 药品 / 精灵球放入时提示“只有战利品能放入安全箱”
12整理顺序点击整理后，顺序为 武器 → 药品 → 精灵球 → 战利品；同类内品质高者在前

体验指引

① 武器栏（默认 3 格）

点卡片切换，再点一次当前武器 = 收起，变成 👊拳头。武器坏了，背包里的备用武器自动补到同一格；全坏光、或没选武器时，攻击键显示拳头。长按武器栏（或按住 Q）出武器轮盘。

② 消耗品袋（默认 5 格）

武器栏左边的圆键：点一下 = 直接用；长按 / 按住 R = 轮盘选快捷道具。某格用完，背包里的同类（没有就其他）消耗品自动补进来。

③ 战利品袋（默认 5 格）

武器栏右边的圆键，操作同消耗品袋（点按用 / 长按轮盘 / 按住 G）。带功能的战利品没有耐久，用完进入冷却，可以一直带出去卖。

④ 轮盘：指哪选哪

按住后往一个方向轻推一点（10 像素）就会选中，也可以直接指向轮盘上的道具。默认松手只把它设为快捷道具，不会立即使用，再点一下按键才用；上方调试配置可以改成"松手立即使用"。回到中间松手 = 取消。

⑥ 背包：双击 / 拖动

消耗品袋、战利品袋里的物品双击 = 放回背包。按住物品拖动，可以放到武器栏 / 消耗品袋 / 战利品袋 / 背包 / 安全箱的格子、拖回容器，或拖到底部"丢弃"。能放的格子亮绿框，不能放的变暗。

⑤ 右下技能

左下 🏃快跑：开关式，开启后移动持续耗体力，耗尽自动关闭。左上 🤸跳跃：可以跳上课桌 / 讲台，怪物够不着。右上 💨冲刺：是否耗体力见上方配置。

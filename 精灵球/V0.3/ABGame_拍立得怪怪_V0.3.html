01一图看懂 按住 → 选中 → 松手 → 吞入 → 吐出相片

是什么

精灵球换成「拍立得怪怪」。一格一台，角标数字 = 相纸张数，一张相纸 = 一次抓取。

怎么用

装到手上后，攻击键变成快门。按住瞄准，松手拍照。

得到什么

成功：怪物相片进背包。失败：怪物被吐回原位，相纸作废。

04按住瞄准 像技能摇杆一样拖动快门转向

按住

脚下出锥形瞄准框，朝向 = 快门拖动方向。没拖时朝角色正前方。

闪光灯预备

按住期间相机闪光灯一直闪。锁到可抓目标时闪得更快。

只锁一只

锥形里有多只时，锁离中线最近的；角度相近的锁更近的。

取消

拖到快门上方「取消」再松手：不拍、不耗相纸。

规则说明
锥形范围半角 30°，长 6 米 待调。只用于选目标和闪光表现，不打群体。
锁定防抖新目标比当前目标更靠近中线 5° 以上才切换 待调，避免标识来回跳。
遮挡隔墙、隔箱子看不到的怪物不出标识，也锁不上。
按住时长不限时，可一直按住找目标。
打断被控制、倒地、换武器、用药：瞄准取消，不耗相纸。普通受击不打断。

05瞄准标识 绿色能抓，红色不能

绿色：可抓，显示本次概率
红色：这台相机抓不了

判断依据

  • 只看「手上相机品阶 × 怪物强度」。
  • 同一只高阶怪，蓝相机看是红色，金相机看是绿色。
  • 首领永远红色。
  • 绿色上的数字已算上低血加成。

08成功与失败

成功：吐出相片，相片品阶 = 相机品阶
失败：怪物被呸回原位，相纸变废片

显影期间

怪物在相机里，谁也打不到。玩家可移动，不能再拍、不能换武器。

失败之后

怪物落回原位，马上恢复行动。不再按品阶给定身时间。

再拍

可以马上对同一只再拍，没有次数限制。

09品阶与概率 相机品阶只改抓取概率，没有别的效果

绿色标识，可抓红色标识，不可抓概率均为初始值 待调

低血加成 沿用

怪物生命低于 50%：概率 ×1.4，上限 95%。所有品阶一样。

高阶怪

只有金、红相机能抓。其他品阶看它是红色。

首领

任何相机都抓不了。是否出专属相机另议。

存放 沿用

1×1，同品阶可叠：白绿 10、蓝紫 5、金 3、红 1。

本版不做额外效果：没有冰冻、致盲、定身时间等品阶差异。闪光只是表现。

带出后刮开，揭晓这只怪物

规则

  • 纯战利品，1×1，不可使用。
  • 品阶 = 所用相机的品阶。
  • 相片上是被拍到的那只怪物。
  • 背包满：相片掉在脚下，可再捡。
  • 带出后进怪物系统，用刮刮卡揭晓。

12制作需求

程序

  • 快门按住、拖动、松手、取消区
  • 锥形选目标：中线最近 + 防抖 + 遮挡
  • 相机品阶 × 怪物强度 → 绿 / 红 / 概率
  • 松手判定；无目标不扣相纸
  • 上下半身分层动画与夹角处理
  • 吞入、显影状态（怪物暂离场）

动作

  • 上半身：举机待机、举机瞄准、拍照
  • 下半身：复用走、跑、倒退走
  • 上下半身混合骨骼遮罩
  • 相机咀嚼、吐片、呸出

美术

  • 拍立得模型 复用
  • 腕带六色（品阶）新增
  • 相片图标模板 + 废片 新增
  • 冰冻机、闪光机换色 不做

动效

  • 锥形瞄准框（地面投影）
  • 闪光灯预备闪烁、锁定快闪
  • 绿色可抓 / 红色不可抓标识
  • 锥形闪光 + 黑白定格、吸入拉丝

音效

  • 按住：闪光灯充电「嘀嘀」
  • 锁定：轻「叮」
  • 快门「咔嚓」、咀嚼三声
  • 出片「滋——」、失败「呸」、无目标「哔」

界面

  • 快门按钮做成可拖动摇杆
  • 快门上方「取消」区
  • 角标数字 = 相纸张数
  • 提示：「没有可抓怪物」「无法抓取」

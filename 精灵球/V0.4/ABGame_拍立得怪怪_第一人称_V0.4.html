01举机 → 对准 → 快门

① 举起相机

点相机槽装备，点「举机」切入 FPS 取景器；叠加取景框、中心准星、倍率 / 距离指示及相纸余量。退出举机回原视角。

② 对准怪物

鼠标 / 触屏拖动转镜头。怪物中心在框内且 ≤6 米、无遮挡、品阶可抓 → 框绿，显示概率；超距 / 不可抓 → 框红并写明原因；无目标 → 中性框。

③ 按快门拍照

点按快门（键盘空格）闪光；0.2s 预备结束再次校验目标，通过才扣 1 张相纸。空拍、红框、取消不消耗。倍率仅帮助观察，不增加射程或概率。

锁定与移动

只锁准星附近的一只，角度相近选距离近的；新目标需更靠近准星 5° 才切换，保留防抖。隔墙不可锁，玩家不可锁。举机可移动（暂按移速不变），无自动追踪；目标离框即失锁。换武器 / 用药 / 被控 / 倒地取消瞄准；普通受击不打断。长按槽位仍只选相机品阶，不拍照。

02核心结果时序 晃的是相纸，不是相机

时间画面与状态
0–0.2s按下快门，预备咔嚓；被控制可取消，不扣纸。
0.2–0.45s二次校验、扣纸、闪光。怪物被拍后在原位置变成一张竖立的大相纸，大小约怪物轮廓 1.3 倍，图像印在纸面上。
0.45–2.10s相纸本身晃 3 下；每下动作约 0.45s + 0.10s 停顿。第 1 下试探，第 2 下加强折角，第 3 下发光蓄势。音高递升、停顿制造紧张；可用边缘亮度暗示概率档位，不提前保证成功。
2.10–2.70s 成功大相纸收缩、沿弧线飞向玩家镜头下方相机，吸入口收片。成功后才进入相机，再结算一张刮刮卡照片入包；怪物从场上移除。
2.10–2.55s 失败相纸裂纹 / 淡出，原地恢复怪物形象：位置、朝向、拍前血量和行为状态保留。怪物抖身 / 愤怒叫一声，立即恢复行动，无额外硬直；不是从相机吐回。
扣纸瞬间由权威端只判一次概率并保留怪物快照；三次晃动不重抽。演出中目标不可受击、不可被他人重复捕获，玩家可移动但不能再拍或换武器。被控 / 倒地不取消已生效的结算；失败恢复拍前状态后继续 AI，成功奖励只发一次。

03取景器试玩 交互示意，不代表最终画质

先举起相机。切换目标可测试红框与空拍；结果由演示选项控制。

04判定沿用 V0.3

一张相纸，一次抓取

一次只抓一只，绿框且校验通过才消耗一张。失败相纸作废，不退还。相机只有一种，腕带六色表示品阶，仅影响抓取概率，不附带冰冻 / 致盲。

低血 / 高阶 / 首领

血量低于 50%：概率 ×1.4，上限 95%。高阶仅金、红相机可抓；首领任何相机都不能抓。绿框概率已算低血加成。

相机资源存放沿用 1×1，同品阶可叠：白绿 10、蓝紫 5、金 3、红 1；角标表示剩余相纸。先补同品阶，再换其他品阶，全空换回武器。此堆叠规则不适用于捕获产物。

05相纸 ≠ 刮刮卡照片

消耗品：空白相纸

拍照前持有，用于支付一次有效捕获。按品阶记录余量，不含怪物信息，不是卡片奖励。

战利品：怪物刮刮卡照片

仅成功后产生，每只怪物一张独立物品，不堆叠；同种怪物抓两只也占两个 1×1 格子，各自保存个体 ID、刮开状态与捕获记录。

卡面绑定怪物设计，而非通用贴图

每个物种独立卡画：纽扣眼用缝线 / 紫绒背景，苔团用叶片 / 孢子纹理，齿轮兽用铜齿 / 铆钉纹理。卡图对应被捕获物种与外形变体，不能随机换成别的怪。初始银色刮层覆盖怪物照片与资料，刮开露出名字、稀有度、怪物图像；预留一项属性 / 收藏加成（数值与是否启用待确认）。

沿用照片品阶 = 所用相机品阶，六色稀有度边框始终可见；物种稀有度另记，避免与相机品阶混淆。命名「未刮开·纽扣眼照片 #个体短码」，揭晓后「纽扣眼·蓝品照片 #短码」。未刮前名称仅作物种归属提示，详细资料在刮层下。

入包与溢出

成功吸入相机后，优先放背包首个空闲格，提示「获得怪物刮刮卡 ×1」。背包满不吞奖励：以未刮照片掉在玩家脚下，保留独立 ID / 卡画，可腾格后拾取；失败不产生卡片。暂按局内收集、带出后在怪物系统刮开；刮开不再占新格、不额外扣相纸，进度按该个体保存，重进继续。

07异常与结算边界

情况处理
无怪 / 超距 / 遮挡 / 红框 / 无相纸提示具体原因，不闪光、不扣纸、不进入三晃。
快门预备内目标离框或被击杀校验不通过，取消且不扣纸。
两人同时拍同一只权威端先校验成功者占用；后者按目标丢失处理，不消耗。
显影中玩家被控 / 倒地已扣纸流程照常；成功按背包 / 满包掉落规则结算，失败恢复原地怪物。
断线 / 重连按捕获事务 ID 恢复结算，怪物快照与奖励互斥；不得重复发卡或重复刷怪。实现方式待程序确认。
失败后再次拍摄立即可再次瞄准，无次数限制；须重新校验并再次消耗相纸。

08制作需求 按原型 → 正式资源拆分

程序

FPS 镜头切换 / 拖动与回退；取景框射线、距离、遮挡、防抖；捕获事务与快照恢复；独立卡片实例 / 满包掉落 / 刮层持久化。

动作

第一人称双手举机、瞄准待机、快门与吸片；第三人称旁观动作同步；失败怪物抖身 / 愤怒反馈。

美术

复用拍立得模型，补近景手部与机身细节；每物种独立卡画、变体、缝线纹理；六色稀有度边框、空白相纸与刮层分图标。

动效

屏幕取景框绿 / 红与原因文字；闪光、大相纸替换、三晃与停顿；成功缩小吸入、失败碎散与恢复；刮屑反馈。

音效

举机轻响、锁定叮、快门咔嚓；三晃纸张扑动音高递升；成功吸片 / 入包提示、失败撕纸 / 怪叫；摩擦刮层声。

界面

准星 / 距离 / 倍率 / 相纸余量；退出举机与快门按钮；独立照片格、卡名 / 框色 / 未刮标记；满包、空拍、超距提示。

09待确认

  1. 是否仅举机时第一人称？暂按退出回原视角；镜头过渡约 0.25s，FOV、眩晕与移动速度需实测。
  2. 手机拖镜头与快门的手指分区、手柄映射如何安排？是否需要辅助瞄准？暂不自动追踪。
  3. 6 米 / 防抖 5° / 倍率显示、概率数字是否合适？先沿用旧概率表。
  4. 每下 0.45s + 0.10s 停顿是否过慢？三晃必须保留，节奏可调，不随品阶增减次数。
  5. 失败恢复拍前行为状态的 AI 快照粒度与原地占位冲突怎么处理？暂保留位置与血量，不加硬直。
  6. 照片品阶继续随相机，物种稀有度单列是否清晰？收藏加成是否启用？演示数值不作为最终奖励。
  7. 刮开入口暂按带出后，局内是否开放？刮开阈值 / 进度保存精度由程序确认。
  8. 首领仍不可抓；若未来做专属相机须另案，不纳入本次。
